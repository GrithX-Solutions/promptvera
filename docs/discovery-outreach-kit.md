## Submission priority

### Tier 1 — Free / editorial, submit first

1. Product Hunt
   - Use a personal account; company accounts cannot post.
   - Self-submission is allowed.
   - New personal accounts normally need to complete onboarding and may have a one-week posting wait.
   - Direct users to the live product, not a press/blog URL.
   - Do not ask people directly for upvotes.
   - Keep the description factual and product-led.

2. SaaSHub
   - Free product submission is available.
   - Submission is reviewed.
   - Domain-email verification can increase priority.
   - Add relevant categories and genuine competitors.
   - Use care@promptvera.com for domain verification when available.

3. AlternativeTo
   - Email verification is required before submitting a new application.
   - Listings go into a review backlog.
   - Position PromptVera as an alternative to relevant prompt-generator products only when functionally defensible.

4. Future Tools
   - Submission form is currently available.
   - Human/editorial review; submission does not guarantee inclusion.
   - If not listed after a week, their FAQ currently says a resubmission is acceptable.
   - Do not repeatedly resubmit inside that period.

5. PRLog
   - Free press-release account and company profile are available.
   - Free releases can include clickable links, tags, industry listings, and a hosted profile.
   - Use for a factual launch announcement, not keyword-stuffed SEO copy.
   - Keep one canonical PromptVera description and link the homepage plus one or two major tools only.

### Tier 2 — Community launch surfaces

6. Peerlist Launchpad
   - Weekly launch surface for products/projects and builder feedback.
   - Use a real founder/builder profile rather than a faceless brand-only approach where the platform expects people.

7. Hacker News / Show HN
   - PromptVera is tryable without signup, which fits one core Show HN requirement.
   - HN explicitly asks posters to write the submission text themselves and not use LLM-generated text.
   - Do not generate or paste AI-written HN launch copy.
   - Do not solicit upvotes or booster comments.
   - Only use Show HN if the person posting actually worked on the project and can stay present in the discussion.

8. BetaList
   - Consider only while PromptVera still qualifies as recently launched.
   - Requires a working website on its own domain and is editorially reviewed.
   - Verify current submission pricing/process before submitting.

## Post-listing checklist

For every approved external profile:

1. Record the live profile URL.
2. Confirm the profile uses the canonical brand name "PromptVera".
3. Confirm the website URL is exactly https://promptvera.com or the intended canonical tool URL.
4. Keep product description and core claims consistent with this document.
5. Record whether the link is followed/nofollowed if measurable.
6. Record the first-seen date in the backlink tracker.
7. After several trusted external profiles are live, add only those real profile URLs to Organization `sameAs` structured data.
8. Do not add unapproved/pending profile URLs to `sameAs`.
