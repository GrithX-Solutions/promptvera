# Homepage Flagship Keyword Research — 2026-10-04

## Status

**VERIFIED deep-research recommendation. No production change is authorized by this document alone.**

Objective: determine whether PromptVera's homepage should operate a flagship prompt-writing tool directly, and identify the strongest keyword/semantic cluster without cannibalizing existing Prompt Enhancer, Prompt Improver, model-specific, or creative-generator pages.

Primary market: United States, English. Secondary validation: UK, Canada, Australia, plus global demand.

## Executive recommendation

Use the homepage to own one canonical intent:

> **Write a new AI-ready prompt from a goal or brief.**

Recommended flagship query phrase: **prompt writer**.

Recommended commercial/tool co-target: **AI prompt generator**.

Recommended supporting semantic phrases: **prompt writer generator**, **AI prompt writer**, **prompt creator**, **prompt generator**, **free AI prompt generator**, **free prompt creator**, **generate a prompt**, and **create prompts for AI**.

Do **not** reposition the homepage around `prompt optimizer`, `prompt enhancer`, `prompt improver`, or `writing prompt generator`. Those phrases either conflict with existing canonical pages or carry a different creative-writing intent.

The flagship should be an actual browser-side prompt-writing utility in the homepage hero, not a directory CTA that sends the user to another page.

## Important qualification: “easy” is not verified

PromptVera currently has Domain Authority 2. Ubersuggest's domain-aware keyword matcher calculated a maximum currently achievable search difficulty of approximately **2.4** for `promptvera.com` and returned no qualifying suggestions in the broad prompt-generator cluster.

Therefore:

- there is **no verified high-volume keyword that is genuinely easy for PromptVera today**;
- content and semantics alone should not be expected to produce top rankings for a 40K-volume head term;
- `prompt writer` is the strongest **relative opportunity**, not a ranking guarantee;
- long-tail discovery, better utility, internal authority, earned links/mentions, and time are still required.

## Community gap

Recent PromptEngineering / ChatGPTPromptGenius discussions repeatedly surface two objections to generic prompt generators:

1. A generator that merely makes a prompt longer can add little value.
2. If important context is missing, a useful workflow should expose the missing information instead of inventing it.

Other community requests favor:
- one specific usable prompt instead of many generic variants;
- simple consumer UX;
- no signup;
- compatibility with multiple AI assistants.

This suggests the homepage should not be a “make this prompt longer” widget. It should convert a **brief/goal into a structured prompt while explicitly surfacing missing details**.

## Recommended homepage flagship product

### Above-the-fold experience

H1 recommendation:

**Free AI Prompt Writer & Prompt Generator**

Supporting copy:

> Turn a goal or brief into a structured prompt you can use with ChatGPT, Claude, Gemini, Grok, and other AI assistants. PromptVera builds the prompt locally in your browser—no login and no paid AI API call.

### Tool interaction

Keep the first interaction simple:

**Required**
- What should AI do? (goal/task)

**Optional / advanced**
- Context or source material
- Audience
- Constraints / must preserve
- Output format
- Tone/style
- Example or reference
- Things to avoid

Primary CTA:
- **Write my prompt**

Output:
- one structured prompt, not a list of generic variants;
- preserve the user's supplied facts;
- do not invent missing business/domain context;
- when an important optional field is absent, use a clear placeholder or a small “Missing details to consider” checklist;
- copy button;
- reset/edit action.

### Intent-preserving next actions

Immediately under the flagship tool:
- **Already have a rough prompt? → Prompt Enhancer**
- **Need to diagnose an existing prompt? → Prompt Improver**
- **Need model-specific structure? → ChatGPT / Gemini / Claude / Grok**

This is important for both UX and cannibalization control.
