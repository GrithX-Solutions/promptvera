## Cannibalization and intent rules

### Broad AI prompt intent

- `/` owns: `ai prompt generator`, `free ai prompt generator`, broad discovery of prompt tools.
- `/prompt-enhancer` owns: `prompt enhancer`, `ai prompt enhancer`.
- `/prompt-improver` owns: `prompt improver`, `ai prompt improver`.
- Do not create a separate `/prompt-optimizer` page unless future SERP research proves a materially different intent/product workflow. Current enhancer/improver pages already cover adjacent optimization jobs.

### Model-specific prompt intent

Each model page owns its model-qualified query family. Do not split `free`, `AI`, or minor wording variants into separate pages.

Examples:
- ChatGPT: `free chatgpt prompt generator`, `chatgpt prompt generator free`, `best free chatgpt prompt generator`.
- Gemini: `google gemini prompt generator`, `gemini prompt generator free`, `free gemini prompt generator`.
- Claude: `claude prompt optimizer` is a secondary term only; do not make a separate optimizer page unless SERP intent diverges.
- Grok: `grok ai prompt generator` belongs to the existing Grok page.

### Image/art intent

- `/ai-image-prompt-generator` owns prompts intended for image-generation models.
- `/drawing-prompt-generator` owns human creative/art prompts such as `draw prompt generator`, `art prompt generator`, `drawing idea generator`, and `random art prompt generator`.
- SERP validation confirms `art prompt generator` is dominated by drawing/art inspiration tools, not AI-image prompt builders.

### Creative themes

- `/random-theme-generator` owns creative `theme generator`, `random themes`, `art theme generator`, and `random art theme generator`.
- Generic `theme generator` has mixed SERP intent including UI/code theme tools. Copy must qualify the page as a creative theme generator.
- Dress-to-Impress/DTI modifiers are excluded unless PromptVera intentionally builds a distinct game-specific utility. They are not semantic filler for the current page.

### Fanfic/OTP

- `OTP prompt generator` is relevant fanfiction/pairing intent in the current SERP and belongs to `/fanfic-prompt-generator`.
- `fanfiction prompt generator`, `fic prompt generator`, `fanfiction ideas generator`, `fanfic idea generator`, `fanfic trope generator`, and `AU ideas generator` all belong to the same page unless a future product change creates a distinct workflow.

### Story plotting

- `/short-story-prompt-generator` owns idea/prompt generation for short-form fiction.
- `/story-plot-generator` owns structured plot construction, including `book plot generator`, `random story plot generator`, `plot generator novel`, and the awkward but relevant search variant `plot story generator`.
- Do not force the exact phrase `plot story generator` into visible copy where it reads unnaturally.
- `/horror-story-plot-generator` owns the horror-specific plot cluster and should not compete with the generic story plot page for non-horror heads.

### Book titles

`/book-title-generator` owns general and genre modifiers unless a genre-specific title tool gains validated, materially distinct functionality:
- `fantasy book title generator`

## Representative competitor-gap review

### Model-specific prompt generators

Current Prompt Builder pages emphasize:
- large preset/template libraries,
- model-specific positioning,
- ready-to-use examples,
- step-by-step usage,
- FAQs,
- reusable/save workflows.

PromptVera should not copy template-count positioning or unverified model-version claims. Its defensible gap is:
- no-signup, deterministic browser-side utility,
- transparent prompt structure,
- concise model-specific guidance sourced from first-party documentation,
- worked examples and failure-mode guidance,
- clean separation between general enhancer/improver and model-specific generators.

### Sora

AgentDock currently exposes controls for video type, style, subject/scene, camera movement, lighting, duration, mood, and optional context, plus a large FAQ surface.

PromptVera's gap is not “more fields.” It is:
- accurate legacy/current-status framing,
- reusable shot/action/camera/lighting/audio prompt anatomy,
- clear separation between prose prompt and product settings,
- continuity and iteration guidance.

### Suno

SunoPrompt currently exposes roughly a dozen musical controls including theme, melody, harmony, rhythm, structure, instrumentation, style/genre, mood, dynamics, production, creativity, and vocals. It also connects the prompt tool to broader music-generation/history workflows.

PromptVera should stay lightweight but make the core musical decision model obvious: genre + mood + tempo/rhythm + instrumentation + vocals + structure + production + exclusions + controlled iteration.

### General creative generators

52 Prompts ranks with a very simple randomizer and a few related-generator links. That leaves room for PromptVera to win on:
- stronger category control,
- examples,
- practical “what next” guidance,
- clearer related-tool paths,
without turning each utility into an article.

Capitalize My Title's journal page uses selectable goal/type/focus controls and extensive links to specific journal-prompt categories. PromptVera should cover category breadth within one strong canonical tool rather than cloning many thin subtype URLs.

### Book titles

GenerateAStory's current tool mainly offers genre, tone, theme, and number-of-title controls with very limited supporting content. PromptVera can add information gain through:
- fiction vs nonfiction distinctions,
- keyword-aware title guidance,
- title-pattern examples,
- evaluation checklist,
- availability/trademark caveat.

## Implementation acceptance criteria

A page-level SEO implementation is complete only when:
- one canonical URL owns the intent and no sibling page competes for it;
- title/H1/introduction reflect the primary intent naturally;
- useful secondary terms appear only where semantically appropriate;
- entities and user questions above are answered without filler;
- the tool itself materially satisfies the query;
